# 09-02 - n8n

## What is it?

[n8n](https://n8n.io) is a fair-code workflow automation platform. It is the self-hosted alternative to Zapier, Make (Integromat), and IFTTT.

With n8n you can:
- Create visual workflows with draggable nodes
- Connect 400+ services (Google, Slack, GitHub, Telegram, etc.)
- Run custom code (JavaScript, Python)
- Use webhooks to integrate with any system
- Schedule executions with time triggers
- Process data with conditional logic, loops, and transformations

## Architecture

```
n8n (container)
    Port: 5678
    |
    +-- PostgreSQL (workflows, credentials, executions)
    +-- (Optional) Redis for queues
```

## Prerequisites

- Docker and Docker Compose installed on the VM
- At least 1 GB free RAM
- Domain configured in Cloudflare (for webhooks)

## Installation

### 1. Access the VM

```bash
ssh ubuntu@192.168.1.100
```

### 2. Create project directory

```bash
mkdir -p ~/n8n
cd ~/n8n
```

### 3. Create .env file

```bash
nano .env
```

```env
# Domain
SUBDOMAIN=n8n
DOMAIN_NAME=meuservidor.com
N8N_HOST=n8n.meuservidor.com

# Port
N8N_PORT=5678

# Timezone (America/Sao_Paulo, Europe/Lisbon, etc.)
GENERIC_TIMEZONE=America/Sao_Paulo

# Security: encryption key (generate a strong one and never change it!)
N8N_ENCRYPTION_KEY=$(openssl rand -hex 32)

# Database connection
DB_TYPE=postgresdb
DB_POSTGRESDB_HOST=postgres
DB_POSTGRESDB_PORT=5432
DB_POSTGRESDB_DATABASE=n8n
DB_POSTGRESDB_USER=n8n
DB_POSTGRESDB_PASSWORD=strong-password-here

# Execution settings
EXECUTIONS_DATA_PRUNE=true
EXECUTIONS_DATA_MAX_AGE=168

# Additional security
N8N_ENFORCE_SETTINGS_FILE_PERMISSIONS=true
N8N_BLOCK_FILE_ACCESS_TO_N8N_FOLDER_FILES=true
```

### 4. Create docker-compose.yml

```bash
nano docker-compose.yml
```

```yaml
services:
  postgres:
    image: postgres:16-alpine
    container_name: n8n-postgres
    restart: unless-stopped
    environment:
      POSTGRES_USER: n8n
      POSTGRES_PASSWORD: strong-password-here
      POSTGRES_DB: n8n
    volumes:
      - n8n_postgres_data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U n8n"]
      interval: 10s
      timeout: 5s
      retries: 5

  n8n:
    image: docker.n8n.io/n8nio/n8n:latest
    container_name: n8n
    restart: unless-stopped
    ports:
      - "5678:5678"
    environment:
      - N8N_HOST=${N8N_HOST}
      - N8N_PORT=${N8N_PORT}
      - N8N_PROTOCOL=https
      - NODE_ENV=production
      - WEBHOOK_URL=https://${N8N_HOST}/
      - GENERIC_TIMEZONE=${GENERIC_TIMEZONE}
      - DB_TYPE=${DB_TYPE}
      - DB_POSTGRESDB_HOST=${DB_POSTGRESDB_HOST}
      - DB_POSTGRESDB_PORT=${DB_POSTGRESDB_PORT}
      - DB_POSTGRESDB_DATABASE=${DB_POSTGRESDB_DATABASE}
      - DB_POSTGRESDB_USER=${DB_POSTGRESDB_USER}
      - DB_POSTGRESDB_PASSWORD=${DB_POSTGRESDB_PASSWORD}
      - N8N_ENCRYPTION_KEY=${N8N_ENCRYPTION_KEY}
      - EXECUTIONS_DATA_PRUNE=${EXECUTIONS_DATA_PRUNE}
      - EXECUTIONS_DATA_MAX_AGE=${EXECUTIONS_DATA_MAX_AGE}
      - N8N_ENFORCE_SETTINGS_FILE_PERMISSIONS=${N8N_ENFORCE_SETTINGS_FILE_PERMISSIONS}
      - N8N_BLOCK_FILE_ACCESS_TO_N8N_FOLDER_FILES=${N8N_BLOCK_FILE_ACCESS_TO_N8N_FOLDER_FILES}
    volumes:
      - n8n_data:/home/node/.n8n
      - ./local-files:/files
    depends_on:
      postgres:
        condition: service_healthy

volumes:
  n8n_postgres_data:
  n8n_data:
```

### 5. Create directory for local files

```bash
mkdir -p ~/n8n/local-files
```

### 6. Start

```bash
cd ~/n8n
docker compose up -d
```

### 7. Verify

```bash
docker compose ps
docker compose logs -f
```

Wait until you see the message: `n8n ready on port 5678`

### 8. Create first admin user

Access `http://192.168.1.100:5678` in your browser and follow the sign-up flow (email, name, password).

## Configure domain in Cloudflare Tunnel

Edit config.yml:

```bash
nano ~/.cloudflared/config.yml
```

Add:

```yaml
  - hostname: n8n.meuservidor.com
    service: http://localhost:5678
```

Restart:

```bash
sudo systemctl restart cloudflared
```

## Advanced configuration

### External Task Runners (recommended for production)

To isolate code execution in separate containers (more secure):

```yaml
  n8n-runner:
    image: docker.n8n.io/n8nio/runners:latest
    restart: unless-stopped
    depends_on:
      - n8n
    environment:
      - N8N_RUNNERS_AUTH_TOKEN=${N8N_RUNNERS_AUTH_TOKEN}
      - N8N_RUNNERS_TASK_BROKER_URI=http://n8n:5679
```

And in `.env` add:
```env
N8N_RUNNERS_ENABLED=true
N8N_RUNNERS_AUTH_TOKEN=$(openssl rand -hex 32)
N8N_TASK_BROKER_PORT=5679
```

### Encryption key backup

The `N8N_ENCRYPTION_KEY` is **irrecoverable**. If you lose it, you will not be able to access saved credentials.

```bash
# Save it in a secure vault! Example local:
echo "N8N_ENCRYPTION_KEY=$N8N_ENCRYPTION_KEY" > ~/n8n-backup-encryption-key.txt
```

## Basic usage

### First workflow

1. Access `https://n8n.meuservidor.com`
2. Click on **New Workflow**
3. Add a **Manual Trigger** node
4. Add a **Set** node
5. Configure: `Value: "Hello from n8n!"`
6. Add a **Webhook** node
7. Execute the workflow and copy the webhook URL
8. Test with curl:
   ```bash
   curl -X POST https://n8n.meuservidor.com/webhook/YOUR-ID
   ```

### Public webhooks

For webhooks to work publicly, Cloudflare Tunnel needs to be active and the domain configured. The webhook URL generated by n8n will use `https://n8n.meuservidor.com/webhook/...`.

## Maintenance

### Update

```bash
cd ~/n8n
docker compose pull
docker compose up -d
```

### Logs

```bash
docker compose logs -f n8n
```

### Full backup

```bash
#!/bin/bash
# ~/n8n/backup.sh

DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR=~/backups/n8n
mkdir -p $BACKUP_DIR

# Database backup
docker compose exec -T postgres pg_dump -U n8n n8n > $BACKUP_DIR/n8n-db-$DATE.sql

# Config volume backup
docker run --rm -v n8n_data:/source -v $BACKUP_DIR:/backup alpine tar czf /backup/n8n-data-$DATE.tar.gz -C /source .

# Compress
gzip $BACKUP_DIR/n8n-db-$DATE.sql

echo "Backup completed: $DATE"
```

## Troubleshooting

| Error | Cause | Solution |
|-------|-------|----------|
| `ECONNREFUSED` on PostgreSQL | Postgres did not start | `docker compose logs postgres` |
| `Encryption key changed` | `.env` differs from original | Restore the original key |
| Webhook not responding | Cloudflare Tunnel stopped | `sudo systemctl status cloudflared` |
| Slow workflow | Low VM RAM | Check `htop`, increase RAM |
| File permission error | Volume mounted incorrectly | Check path in `local-files` |
