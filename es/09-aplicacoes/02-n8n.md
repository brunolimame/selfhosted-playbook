# 09-02 - n8n

## ¿Qué es?

[n8n](https://n8n.io) es una plataforma de automatización de workflows fair-code. Es la alternativa self-hosted a Zapier, Make (Integromat) e IFTTT.

Con n8n puedes:
- Crear workflows visuales con nodos (nodes) arrastrables
- Conectar 400+ servicios (Google, Slack, GitHub, Telegram, etc.)
- Ejecutar código personalizado (JavaScript, Python)
- Usar webhooks para integración con cualquier sistema
- Programar ejecuciones con triggers temporales
- Procesar datos con lógica condicional, bucles y transformaciones

## Arquitectura

```
n8n (contenedor)
    Puerto: 5678
    |
    +-- PostgreSQL (workflows, credenciales, ejecuciones)
    +-- (Opcional) Redis para colas
```

## Prerrequisitos

- Docker y Docker Compose instalados en la VM
- Al menos 1 GB RAM libre
- Dominio configurado en Cloudflare (para webhooks)

## Instalación

### 1. Acceder a la VM

```bash
ssh ubuntu@192.168.1.100
```

### 2. Crear directorio del proyecto

```bash
mkdir -p ~/n8n
cd ~/n8n
```

### 3. Crear archivo .env

```bash
nano .env
```

```env
# Dominio
SUBDOMAIN=n8n
DOMAIN_NAME=meuservidor.com
N8N_HOST=n8n.meuservidor.com

# Puerto
N8N_PORT=5678

# Timezone (America/Sao_Paulo, Europe/Lisbon, etc.)
GENERIC_TIMEZONE=America/Sao_Paulo

# Seguridad: clave de cifrado (genera una fuerte y nunca la cambies)
N8N_ENCRYPTION_KEY=$(openssl rand -hex 32)

# Conexión con base de datos
DB_TYPE=postgresdb
DB_POSTGRESDB_HOST=postgres
DB_POSTGRESDB_PORT=5432
DB_POSTGRESDB_DATABASE=n8n
DB_POSTGRESDB_USER=n8n
DB_POSTGRESDB_PASSWORD=senha-forte-aqui

# Configuraciones de ejecución
EXECUTIONS_DATA_PRUNE=true
EXECUTIONS_DATA_MAX_AGE=168

# Seguridad adicional
N8N_ENFORCE_SETTINGS_FILE_PERMISSIONS=true
N8N_BLOCK_FILE_ACCESS_TO_N8N_FOLDER_FILES=true
```

### 4. Crear docker-compose.yml

```bash
nano docker-compose.yml
```

```yaml
services:
  postgres:
    image: postgres:16-alpine
    container_name: n8n-postgres
    restart: unless-stopped
    environment:
      POSTGRES_USER: n8n
      POSTGRES_PASSWORD: senha-forte-aqui
      POSTGRES_DB: n8n
    volumes:
      - n8n_postgres_data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U n8n"]
      interval: 10s
      timeout: 5s
      retries: 5

  n8n:
    image: docker.n8n.io/n8nio/n8n:latest
    container_name: n8n
    restart: unless-stopped
    ports:
      - "5678:5678"
    environment:
      - N8N_HOST=${N8N_HOST}
      - N8N_PORT=${N8N_PORT}
      - N8N_PROTOCOL=https
      - NODE_ENV=production
      - WEBHOOK_URL=https://${N8N_HOST}/
      - GENERIC_TIMEZONE=${GENERIC_TIMEZONE}
      - DB_TYPE=${DB_TYPE}
      - DB_POSTGRESDB_HOST=${DB_POSTGRESDB_HOST}
      - DB_POSTGRESDB_PORT=${DB_POSTGRESDB_PORT}
      - DB_POSTGRESDB_DATABASE=${DB_POSTGRESDB_DATABASE}
      - DB_POSTGRESDB_USER=${DB_POSTGRESDB_USER}
      - DB_POSTGRESDB_PASSWORD=${DB_POSTGRESDB_PASSWORD}
      - N8N_ENCRYPTION_KEY=${N8N_ENCRYPTION_KEY}
      - EXECUTIONS_DATA_PRUNE=${EXECUTIONS_DATA_PRUNE}
      - EXECUTIONS_DATA_MAX_AGE=${EXECUTIONS_DATA_MAX_AGE}
      - N8N_ENFORCE_SETTINGS_FILE_PERMISSIONS=${N8N_ENFORCE_SETTINGS_FILE_PERMISSIONS}
      - N8N_BLOCK_FILE_ACCESS_TO_N8N_FOLDER_FILES=${N8N_BLOCK_FILE_ACCESS_TO_N8N_FOLDER_FILES}
    volumes:
      - n8n_data:/home/node/.n8n
      - ./local-files:/files
    depends_on:
      postgres:
        condition: service_healthy

volumes:
  n8n_postgres_data:
  n8n_data:
```

### 5. Crear directorio para archivos locales

```bash
mkdir -p ~/n8n/local-files
```

### 6. Iniciar

```bash
cd ~/n8n
docker compose up -d
```

### 7. Verificar

```bash
docker compose ps
docker compose logs -f
```

Espera hasta ver el mensaje: `n8n ready on port 5678`

### 8. Crear primer usuario admin

Accede a `http://192.168.1.100:5678` en el navegador y sigue el flujo de registro (email, nombre, contraseña).

## Configurar dominio en Cloudflare Tunnel

Edita el config.yml:

```bash
nano ~/.cloudflared/config.yml
```

Agrega:

```yaml
  - hostname: n8n.meuservidor.com
    service: http://localhost:5678
```

Reinicia:

```bash
sudo systemctl restart cloudflared
```

## Configuración avanzada

### External Task Runners (recomendado para producción)

Para aislar la ejecución de código en contenedores separados (más seguro):

```yaml
  n8n-runner:
    image: docker.n8n.io/n8nio/runners:latest
    restart: unless-stopped
    depends_on:
      - n8n
    environment:
      - N8N_RUNNERS_AUTH_TOKEN=${N8N_RUNNERS_AUTH_TOKEN}
      - N8N_RUNNERS_TASK_BROKER_URI=http://n8n:5679
```

Y en el `.env` agrega:
```env
N8N_RUNNERS_ENABLED=true
N8N_RUNNERS_AUTH_TOKEN=$(openssl rand -hex 32)
N8N_TASK_BROKER_PORT=5679
```

### Backup de la clave de cifrado

La clave `N8N_ENCRYPTION_KEY` es **irrecuperable**. Si la pierdes, no podrás acceder a las credenciales guardadas.

```bash
# Guárdala en un cofre seguro. Ejemplo local:
echo "N8N_ENCRYPTION_KEY=$N8N_ENCRYPTION_KEY" > ~/n8n-backup-encryption-key.txt
```

## Uso básico

### Primer workflow

1. Accede a `https://n8n.meuservidor.com`
2. Haz clic en **New Workflow**
3. Agrega un nodo **Manual Trigger**
4. Agrega un nodo **Set**
5. Configura: `Value: "Hello from n8n!"`
6. Agrega un nodo **Webhook**
7. Ejecuta el workflow y copia la URL del webhook
8. Prueba con curl:
   ```bash
   curl -X POST https://n8n.meuservidor.com/webhook/TU-ID
   ```

### Webhooks públicos

Para que los webhooks funcionen públicamente, el Cloudflare Tunnel debe estar activo y el dominio configurado. La URL del webhook generada por n8n usará `https://n8n.meuservidor.com/webhook/...`.

```bash

```

### Backup completo

```bash
#!/bin/bash
# ~/n8n/backup.sh

DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR=~/backups/n8n
mkdir -p $BACKUP_DIR

# Backup de la base de datos
docker compose exec -T postgres pg_dump -U n8n n8n > $BACKUP_DIR/n8n-db-$DATE.sql

# Backup del volumen de configuración
docker run --rm -v n8n_data:/source -v $BACKUP_DIR:/backup alpine tar czf /backup/n8n-data-$DATE.tar.gz -C /source .

# Comprimir
gzip $BACKUP_DIR/n8n-db-$DATE.sql

echo "Backup completado: $DATE"
```

## Troubleshooting

| Error | Causa | Solución |
|-------|-------|----------|
| `ECONNREFUSED` en PostgreSQL | Postgres no inició | `docker compose logs postgres` |
| `Encryption key changed` | `.env` diferente del original | Restaura la clave original |
| Webhook no responde | Tunnel Cloudflare detenido | `sudo systemctl status cloudflared` |
| Workflow lento | Poca RAM en la VM | Verifica `htop`, aumenta RAM |
| Error de permiso en archivos | Volumen montado incorrectamente | Verifica la ruta en `local-files` |
