# 09-02 - n8n

## O que e?

[n8n](https://n8n.io) e uma plataforma de automacao de workflows justa (fair-code). E a alternativa self-hosted ao Zapier, Make (Integromat) e IFTTT.

Com o n8n voce pode:
- Criar workflows visuais com nos (nodes) arrastaveis
- Conectar 400+ servicos (Google, Slack, GitHub, Telegram, etc.)
- Executar codigo customizado (JavaScript, Python)
- Usar webhooks para integracao com qualquer sistema
- Agendar execucoes com triggers temporais
- Processar dados com logica condicional, loops e transformacoes

## Arquitetura

```
n8n (container)
    Porta: 5678
    |
    +-- PostgreSQL (workflows, credentials, execucoes)
    +-- (Opcional) Redis para filas
```

## Pre-requisitos

- Docker e Docker Compose instalados na VM
- No minimo 1 GB RAM livre
- Dominio configurado no Cloudflare (para webhooks)

## Instalacao

### 1. Acessar a VM

```bash
ssh ubuntu@192.168.1.100
```

### 2. Criar diretorio do projeto

```bash
mkdir -p ~/n8n
cd ~/n8n
```

### 3. Criar arquivo .env

```bash
nano .env
```

```env
# Dominio
SUBDOMAIN=n8n
DOMAIN_NAME=meuservidor.com
N8N_HOST=n8n.meuservidor.com

# Porta
N8N_PORT=5678

# Timezone (America/Sao_Paulo, Europe/Lisbon, etc.)
GENERIC_TIMEZONE=America/Sao_Paulo

# Seguranca: chave de criptografia (gere uma forte e nunca mude!)
N8N_ENCRYPTION_KEY=$(openssl rand -hex 32)

# Conexao com banco de dados
DB_TYPE=postgresdb
DB_POSTGRESDB_HOST=postgres
DB_POSTGRESDB_PORT=5432
DB_POSTGRESDB_DATABASE=n8n
DB_POSTGRESDB_USER=n8n
DB_POSTGRESDB_PASSWORD=senha-forte-aqui

# Configuracoes de execucao
EXECUTIONS_DATA_PRUNE=true
EXECUTIONS_DATA_MAX_AGE=168

# Seguranca adicionais
N8N_ENFORCE_SETTINGS_FILE_PERMISSIONS=true
N8N_BLOCK_FILE_ACCESS_TO_N8N_FOLDER_FILES=true
```

### 4. Criar docker-compose.yml

```bash
nano docker-compose.yml
```

```yaml
services:
  postgres:
    image: postgres:16-alpine
    container_name: n8n-postgres
    restart: unless-stopped
    environment:
      POSTGRES_USER: n8n
      POSTGRES_PASSWORD: senha-forte-aqui
      POSTGRES_DB: n8n
    volumes:
      - n8n_postgres_data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U n8n"]
      interval: 10s
      timeout: 5s
      retries: 5

  n8n:
    image: docker.n8n.io/n8nio/n8n:latest
    container_name: n8n
    restart: unless-stopped
    ports:
      - "5678:5678"
    environment:
      - N8N_HOST=${N8N_HOST}
      - N8N_PORT=${N8N_PORT}
      - N8N_PROTOCOL=https
      - NODE_ENV=production
      - WEBHOOK_URL=https://${N8N_HOST}/
      - GENERIC_TIMEZONE=${GENERIC_TIMEZONE}
      - DB_TYPE=${DB_TYPE}
      - DB_POSTGRESDB_HOST=${DB_POSTGRESDB_HOST}
      - DB_POSTGRESDB_PORT=${DB_POSTGRESDB_PORT}
      - DB_POSTGRESDB_DATABASE=${DB_POSTGRESDB_DATABASE}
      - DB_POSTGRESDB_USER=${DB_POSTGRESDB_USER}
      - DB_POSTGRESDB_PASSWORD=${DB_POSTGRESDB_PASSWORD}
      - N8N_ENCRYPTION_KEY=${N8N_ENCRYPTION_KEY}
      - EXECUTIONS_DATA_PRUNE=${EXECUTIONS_DATA_PRUNE}
      - EXECUTIONS_DATA_MAX_AGE=${EXECUTIONS_DATA_MAX_AGE}
      - N8N_ENFORCE_SETTINGS_FILE_PERMISSIONS=${N8N_ENFORCE_SETTINGS_FILE_PERMISSIONS}
      - N8N_BLOCK_FILE_ACCESS_TO_N8N_FOLDER_FILES=${N8N_BLOCK_FILE_ACCESS_TO_N8N_FOLDER_FILES}
    volumes:
      - n8n_data:/home/node/.n8n
      - ./local-files:/files
    depends_on:
      postgres:
        condition: service_healthy

volumes:
  n8n_postgres_data:
  n8n_data:
```

### 5. Criar diretorio para arquivos locais

```bash
mkdir -p ~/n8n/local-files
```

### 6. Iniciar

```bash
cd ~/n8n
docker compose up -d
```

### 7. Verificar

```bash
docker compose ps
docker compose logs -f
```

Aguardar ate ver a mensagem: `n8n ready on port 5678`

### 8. Criar primeiro usuario admin

Acesse `http://192.168.1.100:5678` no navegador e siga o fluxo de cadastro (email, nome, senha).

## Configurar dominio no Cloudflare Tunnel

Edite o config.yml:

```bash
nano ~/.cloudflared/config.yml
```

Adicione:

```yaml
  - hostname: n8n.meuservidor.com
    service: http://localhost:5678
```

Reinicie:

```bash
sudo systemctl restart cloudflared
```

## Configuracao avancada

### External Task Runners (recomendado para producao)

Para isolar a execucao de codigo em containers separados (mais seguro):

```yaml
  n8n-runner:
    image: docker.n8n.io/n8nio/runners:latest
    restart: unless-stopped
    depends_on:
      - n8n
    environment:
      - N8N_RUNNERS_AUTH_TOKEN=${N8N_RUNNERS_AUTH_TOKEN}
      - N8N_RUNNERS_TASK_BROKER_URI=http://n8n:5679
```

E no `.env` adicione:
```env
N8N_RUNNERS_ENABLED=true
N8N_RUNNERS_AUTH_TOKEN=$(openssl rand -hex 32)
N8N_TASK_BROKER_PORT=5679
```

### Backup da chave de criptografia

A chave `N8N_ENCRYPTION_KEY` e **irrecuperavel**. Se perde-la, voce nao conseguira acessar as credenciais salvas.

```bash
# Salve em um cofre seguro! Exemplo local:
echo "N8N_ENCRYPTION_KEY=$N8N_ENCRYPTION_KEY" > ~/n8n-backup-encryption-key.txt
```

## Uso basico

### Primeiro workflow

1. Acesse `https://n8n.meuservidor.com`
2. Clique em **New Workflow**
3. Adicione um no **Manual Trigger**
4. Adicione um no **Set**
5. Configure: `Value: "Hello from n8n!"`
6. Adicione um no **Webhook**
7. Execute o workflow e copie a URL do webhook
8. Teste com curl:
   ```bash
   curl -X POST https://n8n.meuservidor.com/webhook/SEU-ID
   ```

### Webhooks publicos

Para webhooks funcionarem publicamente, o Cloudflare Tunnel precisa estar ativo e o dominio configurado. O webhook URL gerado pelo n8n usara `https://n8n.meuservidor.com/webhook/...`.

### Backup completo

```bash
#!/bin/bash
# ~/n8n/backup.sh

DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR=~/backups/n8n
mkdir -p $BACKUP_DIR

# Backup do banco de dados
docker compose exec -T postgres pg_dump -U n8n n8n > $BACKUP_DIR/n8n-db-$DATE.sql

# Backup do volume de config
docker run --rm -v n8n_data:/source -v $BACKUP_DIR:/backup alpine tar czf /backup/n8n-data-$DATE.tar.gz -C /source .

# Compactar
gzip $BACKUP_DIR/n8n-db-$DATE.sql

echo "Backup concluido: $DATE"
```

## Troubleshooting

| Erro | Causa | Solucao |
|------|-------|---------|
| `ECONNREFUSED` no PostgreSQL | Postgres nao iniciou | `docker compose logs postgres` |
| `Encryption key changed` | `.env` diferente do original | Restaure a chave original |
| Webhook nao responde | Tunnel Cloudflare parado | `sudo systemctl status cloudflared` |
| Workflow lento | Pouca RAM na VM | Verificar `htop`, aumentar RAM |
| Erro de permissao em arquivos | Volume montado incorretamente | Verificar caminho em `local-files` |
